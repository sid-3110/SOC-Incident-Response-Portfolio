# SOC Incident Response Portfolio

## 📌 Overview
This repository contains a collection of incident response reports created from a SOC Level 1 analyst perspective.

Each incident demonstrates alert investigation, evidence correlation, incident classification, escalation decisions, documentation, and shift handover.

---

## 🧠 Skills Demonstrated
- Incident identification
- Log correlation (endpoint, network, authentication)
- Phishing investigation
- Malware behavior analysis
- False positive handling
- SOC documentation & handover
- MITRE ATT&CK mapping (high level)

---

## 📂 Portfolio Structure
- Incident reports for multiple security scenarios
- Standardized SOC documentation format


------

## ⚠️ Disclaimer
All incidents are based on simulated or lab environments and are created strictly for defensive security learning.
