## Incident Type:
Unusual Outbound Network Traffic

## Severity:
Medium

## Status:
Escalated

## Summary:
Repeated outbound connections were observed from a user endpoint to an unknown external IP.

## Assessment:
Firewall and DNS logs indicated regular beaconing behavior to a newly registered domain without associated user activity.

## Action Taken:
Alert escalated for further network investigation and containment.

Command and Control
